# Global Completion Theory v1.0 Bundle

This bundle contains:

- `GCT_Global_Completion_Theory_v1.0.md` — canonical UTF-8 source of the paper.
- `global-first-completion/SKILL.md` — Claude Code personal skill.
- `INSTALL.ps1` — Windows PowerShell installer for the skill.
- `README.md` — this file.
- `SHA256SUMS.txt` — hashes for validation.

## Install the Claude Code skill on Windows

Open PowerShell in this folder and run:

```powershell
.\INSTALL.ps1
```

Default destination:

```text
%USERPROFILE%\.claude\skills\global-first-completion\SKILL.md
```

The installer creates the destination directory if needed and copies the canonical `SKILL.md`.

## Skill intent

The skill enforces:

- global-first implementation;
- global coverage before local perfection;
- bounded validation;
- batched root-cause repair;
- proportional risk escalation;
- no automatic security/compliance/administrative category inflation;
- no repeated permission gates for reversible in-scope work;
- global obligation closure before declaring completion.

## Compatibility

This skill can coexist with the previously created `windows-native` skill. They solve different problems:

- `windows-native`: execution-environment invariant.
- `global-first-completion`: work topology and completion invariant.
